\begin{frame}{Project Overview}
\begin{block}{What this project is}
This project studies \textbf{fairness-aware routing under missing context} in two environment families: \textbf{clinical decision support} and \textbf{quantum-network routing}. Both are \textbf{sequential decision systems (SDSs)} that allocate scarce resources under uncertainty and learn from partial feedback.
\end{block}

\begin{columns}[T]
\begin{column}{0.49\textwidth}
\textbf{Goals}
\begin{itemize}
    \item compare \mab, \cmab, and \icmab{} strategies
    \item measure both \textbf{performance} and \textbf{fairness}
    \item show how missing or degraded context can create repeated allocation harm
    \item build a reproducible framework with reportable artifacts
\end{itemize}
\end{column}
\begin{column}{0.47\textwidth}
\textbf{Why it matters}
\begin{itemize}
    \item \textbf{Clinical:} tests, triage, and escalation affect patient outcomes
    \item \textbf{Quantum:} route selection and qubit allocation affect service quality
    \item Aggregate performance can hide harm to specific groups or flows
\end{itemize}
\end{column}
\end{columns}
\end{frame}

% -----------------------------------------------------------------------------
\begin{frame}{Why This Project Matters}
\begin{columns}[T]
\begin{column}{0.48\textwidth}
\begin{block}{Clinical impact}
Routing decisions determine who receives tests, retesting, escalation, or model-assisted attention.
\end{block}
\begin{itemize}
    \item missed context can become missed diagnosis
    \item delayed escalation can compound existing access gaps
    \item subgroup errors can be invisible in aggregate accuracy
\end{itemize}
\end{column}
\begin{column}{0.48\textwidth}
\begin{block}{Quantum-network impact}
Routing decisions determine which flows receive scarce probabilistic resources.
\end{block}
\begin{itemize}
    \item noisy links create partial and delayed feedback
    \item capacity choices affect repeated success or latency gaps
    \item throughput alone does not prove service equity
\end{itemize}
\end{column}
\end{columns}

\vspace{0.5em}
\begin{block}{Core idea}
Fairness-aware routing asks whether the system makes good decisions \textbf{for everyone affected}, not only good decisions on average.
\end{block}
\end{frame}
